# wbr-sitebuilder-views-2020

Six Bootstrap 4 Sitebuilder view experiments from 2020: blank base page, image collages, testimonials, upcoming events, mobile bottom nav.

Each folder was its own repo; its full commit history is preserved here.

| Folder | What it is | Was |
|---|---|---|
| [blank/](blank/) | Blank base page the other views were built on | wbr-sitebuilder-blank-bs4 |
| [image-collage-columns/](image-collage-columns/) | Image collage with card columns | wbr-image-collage-columns |
| [image-collage-flex/](image-collage-flex/) | Image collage with flexbox | wbr-image-collage-flex |
| [testimonials-section/](testimonials-section/) | Testimonial section | wbr-testimonials-section |
| [upcoming-events/](upcoming-events/) | Upcoming-events card section | wbr-upcoming-events |
| [mobile-bottom-nav/](mobile-bottom-nav/) | Mobile nav that fixes to the bottom on scroll | wbr-mobile-bottom-nav |
